# 1С: Конфигурация «Ателье»

Учебная конфигурация для «1С:Предприятие 8.3» (учебная версия), разработанная в рамках практических работ по проектированию информационных систем.

Выгрузка представлена в формате **конфигурации в файлах** (XML), папка `src/`.

## Состав конфигурации

### Справочники

| Справочник | Назначение |
|---|---|
| `Клиенты` | заказчики ателье |
| `Сотрудники` | мастера и закройщики, с квалификацией |
| `Материал` | ткани и фурнитура, с ценой |
| `МоделиОдежды` | модели с описанием и категорией |
| `Работы` | перечень услуг с реквизитом `Стоимость` |

### Документы

| Документ | Назначение | Табличная часть |
|---|---|---|
| `Поступление материалов` | поступление ткани от поставщика | `Материалы` (материал, количество, цена, сумма) |
| `Заказ клиента` | заказ с назначением работы сотруднику и сроком | `Работы` (работа, количество, стоимость) |
| `Заказ материалов` | заказ материалов на основании заказа клиента | `Материалы` |
| `Реализация товара клиенту` | закрытие заказа, передача изделия | `Работы` |

**Ввод на основании:** из документа `Заказ клиента` можно создать `Заказ материалов` и `Реализацию товара клиенту`, реквизит `Основание` заполняется автоматически.

### Перечисления и константы

- перечисления: `ВидыНоменклатуры`, `Квалификации`, `СтатусыЗаказов`;
- константы: `НаименованиеОрганизации`, `ИНН`, `ТелефонОрганизации`.

## Как развернуть

1. Установить «1С:Предприятие 8.3» (подойдёт учебная версия).
2. Создать пустую информационную базу (файловый вариант).
3. В Конфигураторе: `Конфигурация → Загрузить конфигурацию из файлов…` → указать папку `src`.
4. `Конфигурация → Обновить конфигурацию базы данных`.

Или через командную строку:

```bat
1cv8.exe DESIGNER /F"путь_к_базе" /LoadConfigFromFiles "src"
1cv8.exe DESIGNER /F"путь_к_базе" /UpdateDBCfg
```

## Технологии

1С:Предприятие 8.3, встроенный язык (BSL), конфигурация в файлах (XML), управляемые формы.
